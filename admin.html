Database setup

Each file in supabase/ is run once, in order, in the Supabase SQL editor. Everything already ticked below is working; anything missing simply stays quiet on the shop rather than breaking it.

  • schema.sql — settings, so Publish reaches the live shop
  • schema-2-catalogue.sql — products, orders, requests, reviews, posts
  • schema-3-media-reviews.sql — product photographs, offers, visit counts
  • schema-4-uploads.sql — customers can attach a file to a custom print enquiry
  • schema-5-reviews-sales.sql — pinned reviews, and the real "how many sold"
