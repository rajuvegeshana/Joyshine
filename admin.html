Publishing your changes

  1. Preview on site shows your changes in this browser only. Nobody else sees them.
  2. Save changes downloads site.json.
  3. Drop that file into assets/data/ in your GitHub repository (Add file → Upload files → Commit). GitHub Pages redeploys in about a minute.

Supabase connection

Checks the wiring, including whether a stranger could change your shop. Run it after setup and any time something looks wrong.

What this panel does not cover

Adding or editing products, and anything that needs a customer account — orders, stock, reviews. Products live in assets/js/products.js. See section 10 of the README for the free tools that give you a proper form-based editor for those, without leaving GitHub Pages.
